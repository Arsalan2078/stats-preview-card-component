### What I learned

I've discovered the mix-blend-mode property, which was instrumental for completing the assignment.

```css
.imgHolder > img {
  mix-blend-mode: multiply;
}
```

The img was set against a purple background. The multiply value of mix-blend-mode property rendered the black and white image purple. cheers!
